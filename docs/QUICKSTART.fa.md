# شروع کار

این پوشه پروژهٔ اصلی یونیتی است. نمونهٔ قبلی HTML پروژهٔ جداگانه‌ای است و خروجی یونیتی محسوب نمی‌شود.

1. پروژه را با Unity 6000.3.22f1 باز کن.
2. صحنهٔ `Assets/Scenes/StarCatcher.unity` را باز کن و Play را بزن.
3. در محیط بازی دکمهٔ START GAME را بزن؛ حرکت با چپ و راست یا A و D است.
4. ماژول Web Build Support مربوط به همین نسخه را نصب کن.
5. از منوی Star Catcher گزینهٔ Build Web را بزن.
6. بعد از ساخته شدن پوشهٔ Web، در ریشهٔ پروژه دستور `docker compose up -d --build --wait` را اجرا کن.
7. بازی از `http://localhost:8088` باز می‌شود.

خروجی وب در تاریخ ۲۰۲۶/۰۹/۰۹ ساخته و روی همین سیستم با Docker اجرا شد. بارگذاری، امتیاز، برخورد، توقف، پایان بازی و شروع دوباره در مرورگر بررسی شده‌اند. مستندات معماری، استقرار، تست و مسیر ارتقا در همین پوشه قرار دارند. آزمون روی موبایل واقعی و انتشار عمومی هنوز انجام نشده‌اند. برای GitHub، پوشهٔ Library و فایل‌های محلی یا اطلاعات حساب‌ها را ثبت نکن؛ فایل‌های meta باید همراه Assets ثبت شوند.

کامپیوتر میزبان فایل‌ها را ارائه می‌کند و اجرای بازی در مرورگر بازیکن انجام می‌شود. برای دسترسی عمومی بدون IP ثابت می‌توان از تونل استفاده کرد؛ هنوز هیچ تونل یا انتشار عمومی انجام نشده است.

دو هشدار باقی‌ماندهٔ ادیتور: استفاده از Input Manager قدیمی، و اجرای Unity با دسترسی Administrator. اولی در مسیر ارتقای نسخهٔ ۰٫۲ ثبت شده است. برای دومی، هنگام اجرای بعدی Unity از گزینهٔ Run as administrator استفاده نکن. این پیام‌ها مانع اجرای نسخهٔ فعلی وب نیستند.
